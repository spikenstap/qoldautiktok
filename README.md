# Қолдау LIVE

Личное приложение для донатов на Windows и виджетов TikTok LIVE Studio. Без обязательной подписки. Панель ведущего работает локально; для виджетов можно включить временные HTTPS-ссылки через Cloudflare.

## Возможности

- Очередь оповещений, GIF/видео/изображения и звуки по диапазонам сумм.
- Казахская озвучка Piper: Iseke и Raya, скорость и громкость. Читается только комментарий; имя и сумма остаются на экране. Пустой комментарий не озвучивается.
- Музыкальная очередь через официальный встроенный YouTube-плеер, одобрение, пауза, пропуск и приглушение при донате. Аудио не скачивается.
- Отдельные ссылки для донатов, цели сбора, топа и музыки.
- Ручное подтверждение платежей, история, защита от повторного подтверждения и тесты без оплаты.
- Экспериментальный приём уведомлений собственного iPhone через Bluetooth ANCS с настройкой шаблона входящего уведомления Kaspi.

Это не официальный API Kaspi и не банковская сверка. Автопоказ по уведомлениям выключен до настройки и проверки шаблона. Доступность суммы, имени и комментария зависит от данных уведомления. Интеграция с реальным поступлением Kaspi ещё требует проверки; анимация, озвучка и YouTube проверены в LIVE Studio.

## Быстрый запуск из исходников

1. Установи **Node.js 24 или новее** с [nodejs.org](https://nodejs.org/). Нужен встроенный `node:sqlite`.
2. Скачай этот репозиторий: **Code → Download ZIP**, распакуй его.
3. Запусти `START.cmd`. Откроется панель на `http://127.0.0.1:3877` с автоматическим входом. Окно запуска оставь открытым.
4. Открой «Виджеты и ссылки». Для начала отправь тестовый донат, не переводя деньги.

`npm install` не нужен: сервер использует стандартные модули Node.js. Первый запуск создаёт собственные ключи и SQLite-базу в `data/`.

GitHub содержит исходники и инструкции. Исполняемые файлы, большие модели голосов, база, ключи, настройки телефона и персональные ссылки в репозиторий не входят. Для озвучки, HTTPS и Bluetooth установи дополнительные компоненты по [SETUP.md](SETUP.md).

## TikTok LIVE Studio

В LIVE Studio выбери **Добавить источник → Ссылка** и вставь полный адрес из панели. Размеры указаны возле каждого виджета. Включи звук у источника донатов и музыки.

Чтобы получить HTTPS-ссылки, установи `runtime/cloudflared.exe`, затем запусти `START-HTTPS.cmd`. Адреса в панели обновятся автоматически; копия записывается в `HTTPS-LINKS.txt`.

Cloudflare Quick Tunnel временный: адрес меняется после нового запуска, гарантий доступности нет. Постоянный домен и хостинг не настроены. [Документация Cloudflare](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

HTTPS передаёт через Cloudflare данные виджета: имена, суммы, сообщения, цель, топ, медиа и звук. Панель и сырые уведомления телефона остаются локальными. Ссылка с токеном даёт доступ к виджету и очереди воспроизведения — не публикуй её зрителям.

Виджет донатов прозрачен до нового события. Общий экран уже занимает каналы донатов и музыки: закрой его перед использованием отдельных источников. Перед эфиром проверь звук и картинку тестом. Подробности: [HTTPS.txt](HTTPS.txt) и [ВИДЖЕТЫ.txt](ВИДЖЕТЫ.txt).

## Разработка и тесты

```sh
npm test
```

Протокол уведомлений можно проверить без телефона:

```sh
python -m unittest discover -s phone -p "test_*.py"
```

Тесты используют отдельные временные базы и порты. Основные файлы: `server.mjs` — локальный сервер и очередь; `public/` — панель и виджеты; `widget-gateway.mjs` — ограниченный HTTPS-шлюз; `phone/` и `phone-service.mjs` — Bluetooth и обработка уведомлений.
