Модуль Bluetooth загружается…

1. Подключи свой телефон

Открой на iPhone Настройки → Bluetooth и держи телефон рядом.

Нажми «Сопрячь» только возле своего iPhone. Подтверди совпадающий код на телефоне и в окне Windows. Затем обнови поиск и выбери строку «Уведомления».

На iPhone: Bluetooth → ⓘ возле компьютера → разреши системные уведомления. Если пункта пока нет, сначала заверши сопряжение. Эти разрешения подтверждаешь ты.

2. Дождись уведомления Kaspi

После подключения нужен новый входящий перевод. Старые уведомления не воспроизводятся. Дождись обычного поступления — специальный платёж для настройки не обязателен.

Пока уведомлений нет.

Текст хранится на этом компьютере. Если iPhone скрыл сумму или комментарий, приложение не сможет их восстановить. Проверь разрешения уведомлений Kaspi на телефоне.

3. Настрой распознавание

Один раз покажи программе, где в полученном уведомлении сумма, имя и комментарий.

Нужен только для настройки. В эфир остаток не выводится.
Шаблоны распознавания

По одному варианту на строку, до четырёх. Слова о входящем переводе оставь; меняющиеся данные замени на {amount}, {name}, {message}, {balance}. Шаблон для списаний не добавляй.

4. Выведи в эфир

Открой окно эфира и включи в нём воспроизведение. Добавь его в LIVE Studio по инструкции в разделе «Подключение».

Новые распознанные переводы запускают анимацию и выбранный голос. Ссылка YouTube из комментария попадает в музыкальную очередь при достаточной сумме. Если банк не передал комментарий, его не будет в оповещении.

Неоновые виджеты — отдельная ссылка для каждого источника.

Предпросмотр оформления
Донаты, цель, топ и музыка размещаются в сцене независимо. Фон отдельных виджетов прозрачный.
Покажется в активном виджете донатов, без изменения сбора.

Как использовать ссылки

  1. Скопируй ссылку нужного виджета. Она содержит ключ воспроизведения: не публикуй её зрителям.
  2. В LIVE Studio выбери «Добавить источник → Ссылка» и вставь весь адрес. Для HTTPS сначала запусти START-HTTPS.cmd, затем скопируй обновлённую ссылку.
  3. Ссылка для источника запускается автоматически. Если браузер заблокировал звук, открой взаимодействие с источником и нажми «Разрешить звук». Затем отправь новый тест.
  4. Общий экран уже включает донаты и музыку. Закрой его перед переходом на отдельные источники. Один и тот же донат озвучивается только в одном окне.

Локальные ссылки работают на этом компьютере. HTTPS-ссылки доступны через интернет, пока запущен START-HTTPS.cmd; адрес меняется при новом запуске туннеля. Топ — за текущий эфир, без тестовых донатов. Одинаковые имена объединяются; банковского идентификатора отправителя в уведомлении нет.

Подключение к эфиру

Картинка и звук настраиваются отдельно.

Вариант для TikTok LIVE Studio

  1. Нажми «Открыть окно эфира». В нём нажми «Включить воспроизведение».
  2. Оставь окно открытым. В LIVE Studio выбери «Добавить источник» → «Захват окна» и выбери окно «Qoldau — эфир». Если используешь отдельный браузер, захват будет проще настроить.
  3. Обрежь верхнюю часть окна браузера в сцене. В приложении есть кнопка полноэкранного режима.
  4. В микшере LIVE Studio выбери устройство вывода, через которое слышен браузер. Избегай одновременного захвата одного звука двумя источниками.
  5. Отправь тестовый донат. Проверь картинку в сцене и движение индикатора звука. Сделай короткую локальную запись и прослушай её до начала эфира.

Захват окна имеет непрозрачный фон. Прозрачный вариант предназначен для браузерного источника; при наличии источника «Ссылка» проверь, принимает ли твоя версия LIVE Studio локальный HTTP-адрес.

Проверка перед эфиром

  • iPhone подключён, распознавание входящих переводов настроено. Приём по уведомлению не является банковской проверкой операции.
  • Казахский голос выбран после прослушивания.
  • Открыто одно активное окно воспроизведения.
  • YouTube разрешает встраивание выбранного видео. При ошибке виден её код.
  • Звук слышен в тестовой записи LIVE Studio.

При потере окна донаты не повторяются автоматически. Нажми «Возобновить» после переподключения, чтобы продолжить очередь. Уже начатое оповещение останется прерванным.
